## 🛠 Инструкция по установке

### Для Android:
1. Скачайте файл `.apk` на смартфон.
2. Откройте его через загрузки и разрешите установку из неизвестных источников, если система попросит.

### Для iPhone (iOS):
Так как приложения нет в App Store, для его установки вам понадобится собственный сертификат разработчика:
1. Скачайте файл `.ipa` на ваш iPhone.
2. Купите индивидуальную подпись (сертификат разработчика) в любом проверенном магазине сертификатов для iOS.
3. Установите и подпишите скачанный `.ipa` файл прямо на телефоне через приложение **ESign**, **Scarlet** или **GBox**, используя купленный сертификат.
