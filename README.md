## 🛠 Инструкция по установке

### Для Android:
1. Скачайте файл `.apk` на смартфон.
2. Откройте его через загрузки и разрешите установку из неизвестных источников, если система попросит.
3. **При обновлении:** если вы скачиваете новую версию, удалять старое приложение не нужно — просто устанавливайте новый файл поверх текущей версии, чтобы сохранить все ваши закладки и настройки.
   
### Для iPhone (iOS):
Так как приложения нет в App Store, для его установки вам понадобится собственный сертификат разработчика:
1. Скачайте архив `.zip` на ваш iPhone и распакуйте его в стандартном приложении «Файлы», чтобы получить `.ipa`.
2. Купите индивидуальную подпись (сертификат разработчика) в любом проверенном магазине сертификатов для iOS.
3. Установите и подпишите распакованный `.ipa` файл прямо на телефоне через приложение **ESign**, **Scarlet** или **GBox**, используя купленный сертификат.
4. **При обновлении:** устанавливайте новую версию поверх старой с тем же сертификатом. Если сертификат сменился и приложение нужно переустановить начисто — заранее сделайте резервную копию в настройках.
